# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Calypso⁻¹ is a 24-hour hackathon project (HackUTA × Chert "Best Use of FaceTime"): a memory companion for people with dementia. It's a monorepo with four people each owning one track. The repo is currently a **baseplate**: the scaffolds run, but most features are still unchecked tasks in the plan.

- Spec: `docs/superpowers/specs/2026-11-14-calypso-inv-design.md`
- Plan, the source of truth for interfaces, endpoints, tests, and task order: `docs/superpowers/plans/2026-11-14-calypso-inv.md`
- Per-person task files: `docs/tasks/{vishnu-backend,matt-puck,keanu-agent,eric-ios,all-demo}.md`. Each one copies its tasks verbatim from the plan.
- Hour-1 spike decisions: `docs/spikes.md`. Later tasks depend on these values (`AGENT_TRACK_MODE`, `GROUP_CALL_START`, Grok STT/TTS mode, mic device, accelerator), so read it before building on any of them.

## Commands

Python packages use uv, each with its own `pyproject.toml`. Copy `.env.example` to `.env` first.

```bash
cd backend && uv run --group dev pytest                      # also: puck/, agent/
cd backend && uv run --group dev pytest tests/test_models.py::test_card_roundtrip_json   # single test
cd backend && uv run --group dev pytest -m "not live"        # skip tests that call real external APIs
cd backend && uv run uvicorn calypso.app:app --host 0.0.0.0 --port 8000   # once Task 1 creates app.py
cd backend && uv sync --extra ml                             # heavy ML deps (speechbrain, insightface, CLIP, faster-whisper)
cd puck && uv sync --extra cpu                               # tflite-runtime YAMNet on the Pi
```

iOS: the Xcode project is generated by xcodegen from `ios/project.yml`. After adding or removing files, run `xcodegen` in `ios/` and commit the regenerated `ios/Calypso.xcodeproj`.
```bash
xcodebuild test -project ios/Calypso.xcodeproj -scheme Calypso -destination 'platform=iOS Simulator,name=iPhone 17'
xcodebuild test -project ios/Calypso.xcodeproj -scheme Calypso -destination 'platform=iOS Simulator,name=iPhone 17' -only-testing:CalypsoTests/VisitSyncTests   # one test class
```
`Config.swift` reads `API_BASE_URL`, `API_TOKEN`, and `CHERT_PHONE` from Info.plist keys filled from `ios/Config/Base.xcconfig`, which does `#include? ../Secrets.xcconfig`. Copy `ios/Secrets.xcconfig.example` to set them. `*.xcconfig` is git-ignored, so `Base.xcconfig` had to be force-added. The app builds without `Secrets.xcconfig`.

## Architecture

The five parts talk **only through the backend's HTTP API**. `backend/calypso/models.py` (pydantic v2) is the shared contract for the puck, agent, iOS app, and dashboard. Don't change it without telling the team; the Swift models and fixtures mirror it.

- `puck/` (`calypso_puck`), Raspberry Pi worn by the patient: mic capture → webrtcvad segments → YAMNet sound tags → offline queue → `POST /puck/segments`. It must keep recording and queueing with no network. On retry, the server dedupes by `segment_uuid`, so uploads must stay idempotent.
- `backend/` (`calypso`), FastAPI + SQLite on Vultr: ingestion, STT, voice clusters, face identity and `/recognize` fusion, people extracted from setup calls with Claude, visits and photos, the day builder (`/days/{date}/events`), and in-call recall (`/recall`). An in-process event bus (`bus.emit(stage, payload)`) fans out to `GET /stream` (SSE). The backend serves `dashboard/` as static files at `/dashboard`.
- `agent/` (`calypso_agent`), Chert LiveKit FaceTime agent: per-participant (or composite) tracks → `/recognize` → a card scheduler → cards rendered with Pillow as the agent's **outgoing video**. It also runs 1:1 setup calls, the recall loop, and iMessage intake / agent-started group calls.
- `ios/`: SwiftUI app (iOS 17+). Onboarding that adds a `Calypso⁻¹` contact, People, Today timeline, and photo and iOS Visits upload.
- `dashboard/`: plain HTML/JS for judges. It renders bus stages (`puck.segment`, `puck.health`, `recognize`, `recall.detect`, `recall.search`, `card.shown`, `day.built`).

Until Task 1's API is deployed, the agent and iOS tracks build against `FakeBackend` / fixture JSON.

## Rules from the plan

- **Swappable providers:** STT, TTS, sound classifier, accelerator, face model, voice model, and call topology each sit behind one interface with a `Fake*` implementation. Swapping one changes one adapter file and one env var (`CALYPSO_STT`, `CALYPSO_TTS`, `PUCK_SOUND_BACKEND`, `AGENT_TRACK_MODE`). Tests use the fakes. Tests that hit real APIs get `@pytest.mark.live` and are skipped when keys are missing.
- **Never show the wrong person or a made-up place.** Below a threshold, use neutral wording ("Getting to know someone new…", "somewhere with café sounds"). When the top two face scores are close, the result is `uncertain`, never a guess. Starting thresholds live in `config.py` (`FACE_MATCH=0.45`, `FACE_MARGIN=0.08`, `VOICE_MATCH=0.60`, `PLACE_CONF_MIN=0.6`, `RECALL_MIN=0.35`).
- The patient is a `Person` with `is_patient=True` and is never the subject of an identity card.
- In group calls the agent stays silent, except for one confirmation question when learning a new person. Only one card is on screen at a time, for 6–10 s, and a new card never cuts off one that's still under its minimum time. Target: ≤ 2.5 s from the end of a sentence to the card on screen.
- Photos flagged `sensitive` are never searchable or shown.
- Secrets come only from env. Every non-dashboard API call carries `Authorization: Bearer $CALYPSO_API_TOKEN`.
- User-facing name: **Calypso⁻¹**. Code identifiers: `calypso` / `calypso_inv`.
- Models: Claude Sonnet for summaries, Claude Haiku for detection and classification; xAI Grok for STT/TTS.
- Commit messages follow the plan's conventions (`feat(backend): …`, `chore: …`).
